入门研讨会通过引导式介绍，帮助您在无需准备现有应用或详细开发场景的情况下探索 GitHub Copilot。每个研讨会都从简单任务开始，在实际使用过程中逐步介绍产品，并带您完成完整工作流。

每个研讨会都会从空文件夹开始构建同一个 Space Quiz。您可以选择想要学习的工具，也可以完成多个研讨会，比较不同工具的工作方式。

> [!NOTE]
> 这些研讨会由 [James Montemagno][james] 创建，并基于 [GitHub Copilot 入门体验][source-lab]改编。原内容采用 [MIT 许可证][source-license]。

## 研讨会

### [GitHub Copilot app 导览][copilot-app]

从空文件夹开始构建色彩丰富的 Space Quiz，并完成整个开发循环：创建、优化、测试、记录项目说明、发布、规划工作、实现议题、审查并合并拉取请求、自动化重复工作，以及探索 Canvas 扩展。

### [GitHub Copilot CLI 入门][copilot-cli]

学习以终端为中心的工作循环：在 Git 写入任何内容前构建并审查差异，在工作树中并行运行会话，编辑前先规划，管理上下文，然后在不离开 shell 的情况下创建、合并和委派工作。

### [Visual Studio Code 入门][vscode]

体验编辑器中的工作循环：在工作区中构建，从集成浏览器中优化界面，检查上下文，在 Git 写入前测试，编辑前先规划，并在不离开 VS Code 的情况下使用 GitHub 工具处理议题、拉取请求和云会话。
